# Java foundations

Each folder is an independent program.

- [Greeting](greeting/): A short console program that prints a greeting and a synthetic profile.
- [BMI](bmi/): Converts pounds and inches to a BMI value and displays the exercise’s conditional result message.
- [StudentGrades](studentgrades/): Averages three scores and assigns a letter grade using fixed score thresholds.
- [DiscountCalculator](discountcalculator/): Calculates the discount and final price for packages priced at $99 each.
- [InternetBills](internetbills/): Calculates a monthly bill for one of three fixed service plans.
- [MathTutoringGame](mathtutoringgame/): An interactive arithmetic exercise with random addition, subtraction, and multiplication questions.
- [ArraysAndWordFrequency](arraysandwordfrequency/): Finds distinct integers in first-seen order and counts case-insensitive words in a paragraph.
- [Account model and demonstration](account/): A small account class with balance operations, interest calculations, and a console demonstration.
- [Marathon rankings](marathon/): Finds the fastest and second-fastest entries in a list of running times.
