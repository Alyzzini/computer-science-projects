# Java applications

Each folder is an independent program.

- [Phone Directory](phone-directory/): A console phone directory built around an ArrayList of member records.
- [Fast Food Restaurant Order Calculator](fast-food-order-calculator/): A Swing order calculator with sandwich choices, optional sides and drinks, an order summary, and change calculation.
- [Student Information Browser](student-information-browser/): A Swing browser for a small collection of student records, with separate model, window, and application-entry classes.
- [Car Inventory Lookup](car-inventory-lookup/): A Swing vehicle lookup exercise using a HashMap of sample car records.
- [Personal Information Form](personal-information-form/): A Swing form exercise that checks input and displays a local summary.
- [Clothing Catalog Browser](clothing-catalog-browser/): A Swing catalog browser for four clothing records stored in a two-dimensional array.
- [Mama Mia Pizzaria](mama-mia-pizzaria/): A dialog-based pizza order calculator.
- [Body Mass Index Calculator](bmi-calculator/): A small dialog-based exercise in numeric input, arithmetic, and conditional categories.
- [Rectangle Area and Perimeter Calculator](rectangle-calculator/): A Swing calculator for a rectangle's area and perimeter.
- [Five-operation Calculator](five-operation-calculator/): A two-input Swing calculator for five arithmetic operations.
